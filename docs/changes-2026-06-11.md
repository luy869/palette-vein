## 4. frontend全API呼び出しに30秒タイムアウト（c572346）

- **対象**: `frontend/src/api/client.ts`
- **背景**: fetch にタイムアウトがなく、ネットワーク異常時に無期限待ちになる
- **変更**:
  - `withTimeout(signal?)` ヘルパーを追加。`AbortController` + `setTimeout` で30秒後に abort し、呼び出し元の `AbortSignal` も転送する
  - 全12箇所の fetch に適用（signal 引数を取らない `postFeedback` / `me` / `login` 等にも `withTimeout()` を付与）
- **設計ポイント**: タイムアウト時は `controller.abort(new DOMException(..., 'TimeoutError'))` で abort する。既存コンポーネントは `e.name === 'AbortError'` のみ無視するため、タイムアウトは握りつぶされずユーザーにエラー表示される
- **既知の軽微な挙動**: 呼び出し元 signal が既に aborted の場合、タイマーが30秒間残る（abort 済み controller への再 abort は no-op なので実害なし）

## 7. 色検索をSQL内ソートに変更（af6ce28）

- **対象**: `backend/internal/api/search.go`（`handleSearchColor`）
- **背景**: 対象画像（colors あり・横長・未フィードバック）を**全件** Go に読み込み、RGBユークリッド距離を計算して Go 側でソートしていた。画像数の増加に比例してメモリと転送量が増える
- **変更**: SQL内で距離計算とソートを完結させ、上位24件のみ返す
  ```sql
  ORDER BY (
    SELECT MIN(
      power(((v.cv >> 16) & 255) - $2, 2) +
      power(((v.cv >> 8) & 255) - $3, 2) +
      power((v.cv & 255) - $4, 2)
    )
    FROM unnest(i.colors) AS c,
         LATERAL (SELECT ('x' || ltrim(c, '#'))::bit(24)::int AS cv) v
  )
  LIMIT 24
  ```
  - `('x' || hex)::bit(24)::int` は PostgreSQL 標準の hex→int 変換イディオム
  - ソートキーは二乗距離（sqrt は単調なので順序に影響せず省略）
  - 不要になった `colorDistance` 関数と `math` / `sort` import を削除
- **実機検証**（Docker復帰後に実施）:
  - `EXPLAIN ANALYZE`: 12,596件で実行時間 32.5ms
  - `#6644cc` 検索の上位5件は全て `#663399` を含み、距離 2890 = (102-102)² + (68-51)² + (204-153)² が手計算と一致

## 8. Wallhavenレートリミッタの中央集約（beae1ea）

- **対象**: `backend/internal/wallhaven/client.go`
- **背景**: 定期クローラー（1.5秒sleep）と管理画面クロールが**それぞれ独自に** sleep しており、同時実行されると合計リクエスト数が Wallhaven の 45 req/min を超えうる
- **変更**: `Client` に `mu sync.Mutex` + `lastReq time.Time` を持たせ、`Search` の冒頭で前回リクエストから最低1.5秒空くまで待つ「送信時刻予約方式」を実装。並行呼び出しは1.5秒間隔で順に並ぶ
- **レビューで発見したバグ**: Sonnet サブエージェントの初版は `lastReq = time.Now().Add(wait)` としており、前回リクエストから十分時間が経っている場合（wait が負）に `lastReq` が過去になり、**直後の連続リクエストが間隔ゼロで通る**欠陥があった。`next = max(lastReq + interval, now)` を予約する方式に修正
- **補足**: crawler 側の `fetchDelay`（1.5秒sleep）は二重待ちになるが、安全側なので残した
