# changes 2026-06-23

M7: 推薦理由の高度化 — 好みベクトルを CLIP 概念タグ（言葉）に翻訳

---

## 背景・動機

「好きなのがわかるっていうコンセプトなのにまだ推薦元の画像しかわからない」という指摘。
現状の推薦理由は **(b)「似ているいいね画像のサムネ」のみ**で、学習した好みベクトルが人間に読める形になっていなかった。

CLIP（EVA02-L/14）は画像とテキストを同じ768次元空間に埋める。
この性質を使い、**好みベクトルの方向を「概念の言葉」に翻訳**することで「なぜ好きか」を可視化する。
設計書の「推薦理由の高度化」(a) テキストタグ提示 ＋ (c) 系統クラスタの可視化に相当。

---

## 実装内容

### backend: `concepts` パッケージ（新規）

**語彙設計** (`concepts/vocab.go`)
- 固定 curated リスト 95語。{En, Ja} ペアで保持。
- En = EVA02-L/14 の学習分布に合わせた英語句（CLIP 埋め込み用・検索クエリ用）。
- Ja = UI 表示用の日本語ラベル（機械翻訳なし、手作業）。
- カテゴリ: 画風 / 被写体・場所 / キャラクター / ジャンル / 雰囲気 / 色・光 / 視覚要素。

**翻訳ロジック** (`concepts/tagger.go`, `Tag` / `Tagger` 型)
- `Warmup(ctx)`: 全語彙を `EmbedText` で埋め込みキャッシュ（約95 RPC、起動後バックグラウンドで実行）。
  CLIP 未起動時は指数バックオフ（5s→10s→…→2分上限）でリトライ。
- **mean 減算**: 全タグの正規化ベクトルの平均を算出し、クエリ・タグ双方から減算してから再 L2 正規化。
  「万人共通の画像的方向」を除きユーザー固有の好みに近い概念を際立たせる（ゼロショットのため粗いが有効）。
- `Top(vec, k)`: 好みベクトルに近い上位 k 件。weight = スコア/最大スコアで [0,1] 正規化（pill サイズ・不透明度用）。
- `Reason(imgVec, profVec, k)`: min(cos_img, cos_prof) 上位 k 件。「この画像にも好みにも合致する概念」を返す。
  ゼロ以下のスコアはフィルター除去（反対半球の概念を出さない）。

**配線**
- `main.go`: `tagger := concepts.NewTagger(clipClient)` → `go tagger.Warmup(ctx)`（CLIP dial 直後）。
- `api.Server` に `tagger *concepts.Tagger` フィールド追加（`NewServer` 引数変更）。

### backend: 新エンドポイント `GET /api/profile/tags`（`api/concepts.go`）

```json
{
  "tags": [{ "en": "fantasy landscape", "ja": "幻想的な風景", "weight": 0.87 }],
  "clusters": [{ "share": 0.62, "tags": [...] }],
  "cold_start": true,    // いいね不足（省略時 = false）
  "warming_up": true     // Warmup 未完了（省略時 = false）
}
```

- `profileCache.Get` を再利用（recommend ハンドラと同じ）。
- `cold_start` → いいね10件未満（profile == nil の条件と同じ）。
- `warming_up` → Tagger.Ready() == false。
- クラスタが2系統以上のときのみ `clusters` に各系統の上位6タグを付与。

### backend: `recommend.Result.ReasonTags`（`recommend/search.go`）

- `Result` 構造体に `ReasonTags []concepts.Tag `json:"reason_tags"`` を追加。
- `Search(...)` に `tagger *concepts.Tagger` 引数追加。similar 各 item で `tagger.Reason(item.embedding, profile.Vector, 3)` を設定。
- toplist（profile なし）は reason_tags 不要なため設定しない。

### frontend

- **`types.ts`**: `ConceptTag`, `ProfileTagsResponse`, `RecommendItem.reason_tags?` を追加。
- **`client.ts`**: `fetchProfileTags(signal?)` を既存規約（withTimeout + エラー形式）に倣って追加。
- **`ProfilePalette.tsx`**:
  - `fetchProfileTags` を既存 `fetchPalette` と並行取得（毎回再マウント = 鮮度優先の既存設計に合致）。
  - 概念タグ pill セクション（flex-wrap、rounded-full、weight→opacity）をカラードットの前に挿入。
  - タグクリック → 英語句 `en` で `/search?q=<encoded>` に遷移（SearchGrid が受け取る）。
  - 複数系統時: 「好みは N 系統に分かれています」 + 系統別 pill。
  - `cold_start` / `warming_up` 時はそれぞれのメッセージを表示。
- **`RecommendCard.tsx`**: because サムネ行の下に `reason_tags` pill 行を追加（source=similar かつ存在する場合のみ）。日本語ラベル表示、hover で英語句 title。
- **`SearchGrid.tsx`**: `?q=` URL param を hexParam と同じ方式で受け取り、CLIP 意味検索モードで自動実行。

## 設計判断・トレードオフ

| 事項 | 決定 | 理由 |
|------|------|------|
| 語彙サイズ | 95語（固定） | 多すぎると類似タグが競合して精度が下がる。追加は随時可能 |
| 表示 = Ja、埋め込み = En | {En, Ja} ペア | EVA02 は英語中心で En のほうが精度高い。検索クエリも En で精度維持 |
| Warmup タイミング | CLIP dial 直後・バックグラウンド | CLIP のコールドロード(30-60s)を待つ必要があるため非同期。サービスは即時起動 |
| mean 減算 | あり | ゼロショットなのでデフォルト傾向（"digital painting"等が上位になりやすい）を緩和 |
| Reason の min 方式 | min(cos_img, cos_prof) | 「画像にも好みにも強い」= 両方で高いスコアの最小値。and 的結合 |
| ReasonTags クリック | 推薦カードではクリック非対応 | カード内が細かくなりすぎないよう pill は表示のみ。パレットタブ側でクリック可 |
